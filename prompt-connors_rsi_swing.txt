### Strategy & Execution Logic

**1. Universe Filtering & Pre-Market Prep**
- Define a hardcoded list of high-liquidity NSE ticker symbols (`UNIVERSE_TICKERS`, e.g., top 50 Nifty constituents) to prevent bid-ask slippage. 
- Initialize the API using a manual `ACCESS_TOKEN`. 

**2. Late-Day Data Fetch (15:15 PM IST)**
- Remain dormant until exactly 15:15 PM IST.
- Fetch historical daily OHLCV candlestick data (minimum 250 days to allow for 200-SMA and 100-day Percent Rank calculations) for every ticker in `UNIVERSE_TICKERS` via the Upstox v2 historical endpoint.
- **Rate Limit Handling:** Use an `asyncio.Semaphore(10)` and exponential backoff to fetch these histories concurrently without triggering HTTP 429 bans.

**3. Component Calculation (ConnorsRSI 3, 2, 100)**
- Use `pandas` and `numpy` for fast, vectorized calculations. For each ticker, compute:
  - **200-day SMA** and **5-day SMA** of the closing price.
  - **Price Momentum:** 3-period standard RSI of the close.
  - **Streak Duration:** Calculate the consecutive days up (positive integer) or down (negative integer). Apply a 2-period RSI to this streak array.
  - **Relative Magnitude:** A 100-period Percent Rank evaluating today's percentage price change against all daily percentage changes over the last 100 days.
  - **CRSI Score:** `(Price Momentum + Streak Duration + Relative Magnitude) / 3`.

**4. Signal Generation & Risk Filtering (15:25 PM IST)**
- **Trend Filter:** Current Close > 200-day SMA.
- **Trigger:** CRSI Score < `CRSI_THRESHOLD`.
- **Position Sizing:** For passing tickers, calculate the quantity to buy by allocating exactly `POSITION_SIZE_PCT` (e.g., 5%) of `TOTAL_CAPITAL` divided by the current LTP.
- **Inventory Check:** Exclude any ticker that is already currently held in the open portfolio.

**5. Order Execution (15:28 PM IST)**
- Dispatch aggressive LIMIT BUY orders (LTP + `SLIPPAGE_BUFFER_TICKS`) at 15:28 PM to lock in the near-close signal price.
- Persist fill data to an in-memory ledger and append to the paper/live CSV logs.

**6. Exit Evaluation (Evaluated Daily at 15:15 PM on Open Positions)**
- **Dynamic Target Exit:** If a held stock's current LTP crosses above its 5-day SMA, dispatch a LIMIT SELL order at 15:28 PM.
- **Time-Based Exit:** Hard stop-losses degrade this model. If a position has been held for `MAX_HOLD_DAYS` without hitting the 5-day SMA target, forcefully liquidate it at 15:28 PM to free up capital.
